# Wellness e Solution — Single-page website

A responsive, dependency-free static website. It can be hosted on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any regular web server.

## Preview locally

Open `index.html` directly in a browser, or run any static server in this folder.

## Deploy

Upload the entire folder while keeping `index.html`, `styles.css`, `script.js`, and `assets/` together. No build command is required.

## Before publishing

Update the phone number, email address, physical address, and any service copy in `index.html`.

The enquiry form submits through FormSubmit and delivers to `wellnessesolution@gmail.com`, with a copy to `wellnessesolutionnoida@gmail.com`. The first submission triggers a one-time activation email from FormSubmit; the recipient must open that email and approve the form before enquiries are forwarded.
